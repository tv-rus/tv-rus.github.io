# Персональный IPTV-плейлист

`generate_playlist.py` скачивает и объединяет три русскоязычных M3U-плейлиста:

1. `iptv-org` — основной источник с наивысшим приоритетом;
2. `duckkota` — дополнительный источник;
3. `smart-iptv.ru` — дополнительный источник.

Генератор:

- удаляет точные дубликаты потоков по URL;
- объединяет одинаковые каналы по `tvg-id`, а при его отсутствии — по названию;
- сохраняет альтернативные URL как отдельные записи `[Резерв N]`;
- группирует каналы в `ТВ`, `Кино`, `Спорт` и `Детские`;
- переносит `tvg-id`, `tvg-logo` и EPG (`x-tvg-url`) из исходных плейлистов;
- поддерживает пользовательские фильтры по регулярным выражениям;
- умеет параллельно проверять HTTP/HLS-потоки и ставить рабочий вариант первым;
- по умолчанию убирает радио, камеры, магазины, взрослые и тестовые каналы;
- ставит первыми каналы из `rating-tv.md` в порядке их мест, затем добавляет остальные; распознаёт русские и известные латинские названия/`tvg-id`, включая SD/HD-варианты, без смешения с тематическими и региональными каналами.

## Генерация

Требуется Python 3.9 или новее. В корне репозитория выполните:

```sh
python docs/generate_playlist.py
```

Результат будет записан в `docs/ru.m3u`. Порядок приоритетных каналов читается из таблицы `docs/rating-tv.md`: достаточно изменить места или названия в файле и запустить генератор снова. Атрибуты групп сохраняются, поэтому TiviMate продолжит показывать категории независимо от физического порядка записей.

Чтобы исправить порядок в уже готовой подписке, не скачивая источники заново и не меняя состав, URL потоков, метаданные и резервы:

```sh
python docs/generate_playlist.py --sort-existing docs/ru.m3u --sort-existing docs/my-tv.m3u
```

Команда перезаписывает указанные файлы на месте; `--rating` позволяет выбрать другую таблицу. Резервные записи остаются рядом с соответствующим основным вариантом в прежнем порядке. Отсутствующие каналы из рейтинга не добавляются. В опубликованном плейлисте первыми идут доступные варианты «Россия 1», затем НТВ, Первый канал, Пятый канал и далее по таблице.

После публикации изменённого файла обновите подписку в плеере. Если в нём включена собственная алфавитная или ручная сортировка, выберите **порядок из плейлиста**, иначе порядок файла может не отображаться.

Проверка сортировки без сети:

```sh
python -m unittest discover -s docs -p test_generate_playlist.py -v
```

Для получения наиболее рабочего списка рекомендуется проверить потоки:

```sh
python docs/generate_playlist.py --check-streams --drop-unavailable
```

`--check-streams` ставит ответивший поток первым, даже если он пришёл из источника с более низким приоритетом. Проверка загружает начало потока и отклоняет пустые ответы, HTML-заглушки и ответы API с ошибкой. `--drop-unavailable` удаляет потоки, которые не прошли проверку за 5 секунд; URL с протоколами, отличными от HTTP/HTTPS, в строгом режиме также удаляются. Проверка показывает доступность в момент запуска, а не гарантирует дальнейшую работу канала.

Можно увеличить тайм-аут для медленного подключения:

```sh
python docs/generate_playlist.py --check-streams --drop-unavailable --check-timeout 10
```

Можно выбрать другое расположение или файл рейтинга:

```sh
python docs/generate_playlist.py --output ru.m3u --rating docs/rating-tv.md
```

## Отбор каналов

`--include` оставляет только совпавшие каналы, `--exclude` удаляет совпавшие. Параметры можно повторять; регистр не учитывается.

Например, оставить федеральные каналы и спорт, но убрать shopping-каналы:

```sh
python docs/generate_playlist.py \
  --include "первый|россия|нтв|матч|спорт" \
  --exclude "shop|магазин"
```

Без пользовательских фильтров сохраняются все найденные телеканалы, кроме типичного мусора: радио, веб-камер, магазинов, взрослых, погодных и тестовых каналов. Вернуть их можно параметром `--keep-noise`. Каналы, которые не удалось распознать как кино, спорт или детские, попадают в группу `ТВ`.

## Публичный URL

После публикации GitHub Pages плейлист доступен по адресу:

```text
https://tv-rus.github.io/ru.m3u
```

GitHub Pages публикует содержимое `docs/` из ветки `main`; после обновления `docs/ru.m3u` достаточно выполнить push.

## TiviMate на AM7

1. Сгенерируйте `ru.m3u`.
2. Передайте файл на AM7 либо опубликуйте содержимое `docs/` через доступный устройству HTTP-сервер.
3. В TiviMate выберите **Добавить плейлист → M3U-плейлист** и укажите путь или URL файла.
4. При обновлении источников повторно запустите генератор и обновите плейлист в TiviMate.

Резервные потоки показываются рядом с основным каналом как отдельные записи. Без проверки основной поток берётся из источника с наивысшим приоритетом. С `--check-streams` первым становится доступный поток, а при равном результате сохраняется приоритет источников.

## Свои источники

Каждый `--source` добавляет источник; порядок аргументов определяет приоритет:

```sh
python docs/generate_playlist.py \
  --source "https://example.com/main.m3u" \
  --source "https://example.com/backup.m3u"
```

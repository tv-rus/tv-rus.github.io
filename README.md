# ТВ-Русь — подписка каналов РФ

Добавьте в IPTV-плеер URL обновляемой подписки:

```text
https://tv-rus.github.io/ru.m3u
```

В TiviMate выберите «Добавить плейлист → M3U». Чтобы сохранить порядок каталога, используйте **порядок из плейлиста**, а не алфавитную сортировку.

## Варианты подписки

- Основной: https://tv-rus.github.io/ru.m3u — один канал, один выбранный **primary** (основной поток), без отдельных резервных записей.
- Тот же список: https://tv-rus.github.io/playlists/best.m3u.
- Только недавно проверенные: https://tv-rus.github.io/playlists/online.m3u.
- С резервами: https://tv-rus.github.io/playlists/all.m3u — основной поток и до двух резервов `[Резерв N]` при стандартных настройках, без повторяющихся URL.
- Опционально, только в сборках с `--with-conservative`: `playlists/conservative.m3u` — subset свежих online потоков с sampled-track оценкой `conservative-avc`, с основным и до двух совместимых резервов. Может содержать ноль каналов (только `#EXTM3U`); наличие проверяйте по manifest. Это не гарантия поддержки устройства или всего adaptive manifest: URL не переписываются, проверены только sampled tracks. Основная подписка от включения варианта не меняется.
- Машиночитаемый каталог каналов, потоков и их состояния: https://tv-rus.github.io/catalog.json. Новые сборки добавляют metadata v1 с исходными именами, категориями и порядком справочника; непроверенные связи явно отмечены `review`. Additive `feed_media` v1 описывает подтверждённые эфиры, разрешённые media sources и известные качества; master/MPD сохраняется для адаптации плеера. Рекомендация сервера не задаёт качество зрителю, а возраст probe не гарантирует доступность. До двух выбранных резервов — лимит источников, не разрешений. Возможности нового формата не означают, что обновление уже выпущено.
- Архив: ориентировочная таблица 2025 года, сохранённая по прежнему адресу только для совместимости (не действующий порядок): https://tv-rus.github.io/rating-tv.md.
- Контрольные суммы результатов одной генерации: https://tv-rus.github.io/manifest.json.
- В новых staged-сборках — безопасная агрегированная сводка: `health-summary.json` (наличие проверяйте по manifest). Времена и ревизии успешных стадий, счётчики выбора и freshness относятся к одному runner, а не ко всем регионам. `last_success.deploy` — последняя отдельно подтверждённая предыдущая Pages-сборка; `null` означает отсутствие подтверждения, а не успех текущей публикации.

В новых сборках группы берутся из документированных категорий базового справочника: например, Новости, Кино и сериалы, Спорт и Детские. Неизвестные категории остаются в группе «Без категории», без догадок по имени канала. Порядок каталога от группы и смены потока не зависит. Идентификаторы и логотипы сохраняются из источников с локальными поправками. Ссылки на телепрограмму могут передаваться из источников; отдельного объединённого EPG сервис не создаёт.

В новых сборках подтверждённые ID-связи используют исходное имя CSV без перевода
или технических добавок источника; статус проверки имени хранится отдельно.
Стабильные ID не меняются, региональные/временные эфиры не объединяются по имени.
Непривязанные записи сохраняют legacy-имя и не получают принятые CSV-метаданные
только из-за появления в upstream.

Порядок новых сборок — порядок базового каталога CSV, а не единый измеренный
ТВ-рейтинг всех 867 каналов. При этом исходный CSV упорядочен с использованием
ТВ-доли и просмотров RUTUBE; это производный порядок, а не независимая алфавитная
сортировка. Публикация новых CSV-метаданных и порядка ожидает отдельного
согласования условий использования данных; описание формата не означает, что
обновление уже выпущено. Измерения ТВ-аудитории есть лишь у 33 каналов за
2026-11-02–2026-11-08 с отдельными параметрами выборки. Пропуск измерений не означает
нулевую аудиторию или низкий рейтинг; архивные оценки 2025 года их не заполняют.

## Статический API v1

Новые сборки дополнительно содержат `api/v1/index.json`: ссылки на карточки каналов,
категории, локальный поисковый индекс, health и автоматически сформированный
`api/v1/subscriptions.json` с доступными подписками и их SHA-256. Схема —
`api/v1/schema.json`, маршруты — `api/v1/openapi.json`. Наличие проверяйте по manifest:
описание формата не означает, что новая сборка уже опубликована.

JSON компактен; крупные выдачи также имеют отдельные `.json.gz` файлы для скачивания
и распаковки. Поиск выполняется в клиенте по нормализованным именам, не HTTP query.
ID карточек совпадают с публичным каталогом; имена, URL и порядок не являются ID.
Неизвестные поля v1 нужно игнорировать, nullable значения не означают подтверждённые
данные. Полная иерархия эфиров и качеств остаётся в `catalog.json.feed_media`.

## Резервы и переключение в плеере

`ru.m3u` содержит один выбранный primary на канал. При очередном обновлении сервер
может выбрать другой допустимый поток; плеер увидит изменение после перезагрузки
подписки. Это не переключение во время просмотра.

`playlists/all.m3u` содержит primary и **только выбранные** резервы, а не все
найденные ссылки. Обычный M3U не задаёт универсальный автоматический failover:
в TiviMate и других плеерах записи `[Резерв N]` могут отображаться как отдельные
каналы, которые нужно выбрать вручную. Поведение зависит от конкретного плеера,
его версии и настроек; поддержка TVGo режима «Авто» проверяется отдельно по JSON
контракту, а не предполагается из наличия M3U. Смена качества внутри HLS master/MPD
не равна переходу на другой независимый источник.

## Доступность и источники

В новых сборках известные NSFW-записи базового справочника и локально запрещённые
каналы/ссылки исключаются независимо от наличия рабочих потоков. Присутствие канала
в справочнике или историческое число ссылок не является допуском к публикации.

Подписка объединяет российские подборки iptv-org, Free-TV и DuckKota. Эти каталоги могут использовать общие исходные ссылки: три каталога не означают три независимых поставщика эфира.

Плановое обновление — каждые 6 часов. Строгая генерация проверяет наличие видеопакетов; `online` означает успешную проверку не старше 24 часов, а не полное декодирование и не гарантию работы у вас. Ограничения доступа, сеть и ссылки могут меняться. При сборке без новой проверки основной список может содержать непроверенные или устаревшие варианты; для свежих результатов используйте `online.m3u`. Резервы не гарантируют независимость или бесперебойность.

Видео не хранится и не ретранслируется. Это бесплатная подписка на список ссылок, не продажа доступа к телевидению. Публичность URL не подтверждает права на просмотр или распространение: соблюдайте условия вещателя и местное законодательство. Ответы 401/403/451 означают ограничение доступа, но не обязательно геоблокировку.

Лицензии кода не распространяются автоматически на данные, а лицензии справочников не предоставляют прав на эфир, логотипы или EPG. Указание источника само по себе не заменяет разрешения; применимость условий к обогащённым именам, категориям и производному порядку требует отдельного согласования. По вопросам прав или ошибочных ссылок откройте issue в репозитории подписки, указав канал, URL и основание запроса; ссылки могут быть удалены.
